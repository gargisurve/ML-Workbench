# ML Workbench — Machine Learning Platform

ML Workbench is an interactive machine learning application designed to support the end-to-end workflow of building, evaluating, and comparing machine learning models.

The project brings together data exploration, preprocessing, model training, prediction, evaluation, and model export in a modular interface.

## Features

### 1. Dataset Management
- Load and inspect datasets.
- Explore dataset structure and data types.
- Examine missing values and summary statistics.

### 2. Exploratory Data Analysis
- Visualize distributions and relationships between variables.
- Explore numerical and categorical features.
- Identify patterns and potential data-quality issues.

### 3. Data Preprocessing
- Handle missing values.
- Encode categorical variables.
- Prepare features for machine learning.
- Apply suitable preprocessing techniques.

### 4. Machine Learning
- Train supported machine learning models.
- Configure model parameters where implemented.
- Generate predictions from trained models.

### 5. Evaluation and Comparison
- Evaluate models using appropriate performance metrics.
- Compare models using a consistent evaluation process.
- Review results to understand model performance.

### 6. Prediction and Export
- Generate predictions for new data.
- Export supported outputs and model artifacts.

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib and Seaborn, where used

## Application Workflow

Dataset → Exploration → Preprocessing → Model Training → Prediction → Evaluation → Model Comparison → Export

## Getting Started

### Prerequisites
